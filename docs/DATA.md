# Data sources and fixed partitions

## Fluorescence measurements

Source study: Gonzalez Somermeyer et al. (2022), *Heterogeneity of the GFP fitness landscape and data-driven protein design*, [eLife 11:e75842](https://doi.org/10.7554/eLife.75842).

Source repository: [Orthologous_GFP_Fitness_Peaks](https://github.com/aequorea238/Orthologous_GFP_Fitness_Peaks), commit `799bd76889918bf1551c60016fb23278024cac73`.

Direct download: [final amino-acid genotypes and brightness](https://raw.githubusercontent.com/aequorea238/Orthologous_GFP_Fitness_Peaks/799bd76889918bf1551c60016fb23278024cac73/data/final_datasets/amacGFP_cgreGFP_ppluGFP2__final_aminoacid_genotypes_to_brightness.csv).

Select `gene == "ppluGFP"` in that source. The modelling label is `log10(replicates_mean_brightness)`. All 31,480 genotypes in the frozen modelling input were matched back to this source; their labels agree to less than 1e-12. The source contains additional records. Exact reproduction uses the supplied processed sequences and row order, not a newly filtered or shuffled copy of the upstream table.

`python reproduce.py fetch data` installs:

- `experiment/repro_project/data/raw/pplu_31480_sequences.csv`: the original ordered modelling input. `medianBrightness` contains log10 fluorescence. Its historical `split` column is not the current benchmark split.
- `experiment/data/unique_sequences.csv`: the 31,434 unique sequences, stable `row_id`, sequence SHA256, label, mutation depth and random partition.
- `train.csv`, `validation.csv`, `calibration.csv`, `test.csv`: the fixed random partitions.
- `depth_extrapolation.csv`: the separate mutation-depth partition.
- `experiment/repro_project/data/processed/reference_sequence.txt`: the 221-residue ppluGFP2 reference, excluding the initiating methionine.
- `experiment/artifacts/embeddings/P4_glom_original.npy`: mutation status and the three mutant residue-class channels. These are also regenerated by `position_features.py`.

Original `aaMutations` annotations are retained, including terminal annotations outside the 221-residue modelling reference. The archived sequence column defines the model input. Duplicate sequences are reduced by retaining the first original row before the current split is assigned; duplicates cannot cross partitions.

The random split is determined by sorting SHA256(`glom-independent-20261013:` + sequence). It is independent of brightness. `prepare_data.py` contains the construction; `configs/SPLITS.json` records the counts and exact file hashes. To independently rebuild it without modifying the frozen inputs:

```bash
python experiment/prepare_data.py --project experiment/repro_project --output reproduced/rebuilt_splits
```

## Public model inputs

`manifests/PUBLIC_ASSETS.json` records model repositories, upstream revisions, file sizes and SHA256 values. The downloader verifies each file. Use:

```bash
python reproduce.py assets esm2_150m
python reproduce.py assets esm2_650m esmc_600m esmc_6b saprot_650m_af2 esm2_native650
```

The frozen ESM2-to-SaProt Bridge is a project-specific checkpoint provided in `weights`, not a public model download. General SaProt pretraining weights are used for the matched baseline fits; no external fluorescence-finetuned model is substituted.

## Structural inputs

The experimental reference is [PDB 2G3O](https://www.rcsb.org/structure/2G3O), chain C. `biophysics/inputs/` contains the exact reference used, the Top 30 candidates, their starting sequences and the WT/start/candidate system mapping. `md_inputs` provides the prepared mature-chromophore structures, Amber topologies and coordinates. MD trajectories are not distributed here.

## Provenance

`manifests/DATA_SOURCES.json` records the upstream data validation. `manifests/ASSETS.json` identifies every distributed input and fitted weight. `experiment/artifacts/discovery_v3/PROTOCOL.json` retains the primary search input identities and parameter provenance; `configs/SEARCH_HPO_TRIAL12.json` makes the effective settings easy to inspect. This is the historical confirmed policy used for the reported campaign; rerunning it does not imply a new hyperparameter search.
